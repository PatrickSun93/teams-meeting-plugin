# User Installation Guide - Teams Meeting Transcription App

A simple, step-by-step guide for end users to install and use the Meeting Transcription app.

## 🚀 Quick Start (5 minutes)

### Step 1: Install the App
1. **Open Microsoft Teams** (desktop or web)
2. **Click "Apps"** in the left sidebar
3. **Search for "Meeting Transcription"** or find it in your organization's apps
4. **Click "Add"** to install the app

### Step 2: First Meeting Test
1. **Start or join a Teams meeting**
2. **Click "Apps"** in the meeting toolbar (top of screen)
3. **Select "Meeting Transcription"** from the list
4. **If you're the host:** Click "Start Transcription"
5. **If you're a participant:** You'll see the transcription status

### Step 3: Review Results
- **During meeting:** See real-time transcription
- **After meeting:** Find transcript and AI summary in the chat

## 📖 Detailed Installation Instructions

### For Desktop Teams App

1. **Open Microsoft Teams Desktop App**
   - Launch Teams from your desktop or Start menu
   - Sign in with your work or school account

2. **Navigate to Apps**
   - Look for "Apps" in the left sidebar
   - Click on it to open the Apps section

3. **Find the Meeting Transcription App**
   - **Option A:** Search for "Meeting Transcription" in the search bar
   - **Option B:** Look in "Built for your org" section
   - **Option C:** Check "Manage your apps" if previously installed

4. **Install the App**
   - Click on the "Meeting Transcription" app
   - Review the app description and permissions
   - Click "Add" or "Install" button
   - Wait for installation to complete

5. **Verify Installation**
   - The app should now appear in your "Manage your apps" section
   - You'll see it available in meeting toolbars

### For Teams Web App

1. **Open Teams in Browser**
   - Go to teams.microsoft.com
   - Sign in with your credentials
   - Use Chrome, Edge, or Firefox for best experience

2. **Access Apps Section**
   - Click "Apps" in the left navigation
   - This opens the Teams app store

3. **Install the App**
   - Search for "Meeting Transcription"
   - Click on the app when found
   - Review permissions and click "Add"

4. **Grant Browser Permissions**
   - Allow microphone access when prompted
   - This is needed for transcription to work

## 🎯 Using the App in Meetings

### For Meeting Hosts/Organizers

**Before the Meeting:**
1. **Start your Teams meeting** as usual
2. **Wait for participants** to join
3. **Prepare to enable transcription** when ready

**During the Meeting:**
1. **Click "Apps"** in the meeting toolbar
2. **Select "Meeting Transcription"**
3. **Click "Start Transcription"**
4. **Grant microphone permissions** if prompted
5. **Monitor the real-time transcription** display
6. **Use controls** to pause/resume as needed

**After the Meeting:**
1. **Transcription stops automatically** when meeting ends
2. **Complete transcript** is sent to meeting chat
3. **AI summary** follows shortly after
4. **Review and share** as needed

### For Meeting Participants

**During the Meeting:**
- **See transcription status** in the app
- **View real-time text** as people speak
- **No controls needed** - everything is automatic

**After the Meeting:**
- **Find transcript** in the meeting chat
- **Read AI summary** for key points
- **Access saved transcripts** through the app

## ⚙️ First-Time Setup

### Basic Configuration

1. **Open the App**
   - Go to Apps → Meeting Transcription
   - Click to open the main interface

2. **Choose Transcription Service**
   - **Local Processing:** More private, works offline
   - **Cloud Services:** Higher accuracy, requires internet
   - Select based on your needs and organization policy

3. **Configure API Keys (if using cloud services)**
   - **OpenAI:** Enter your OpenAI API key
   - **Azure:** Configure Azure Speech Services
   - **Claude:** Set up Anthropic API access
   - Contact your IT admin if you need help with keys

4. **Customize Summary Prompts**
   - **Use default prompts** for standard meetings
   - **Create custom prompts** for specific meeting types
   - **Save templates** for recurring meeting formats

### Privacy Settings

1. **Data Storage Options**
   - **Local Only:** All data stays on your device
   - **Cloud Enhanced:** Uses cloud for better accuracy
   - Choose based on your privacy requirements

2. **Retention Settings**
   - **Auto-delete:** Set how long to keep transcripts
   - **Manual cleanup:** Delete transcripts when done
   - **Export options:** Save important transcripts

## 🔧 Troubleshooting Common Issues

### App Won't Install

**Problem:** Can't find or install the app
**Solutions:**
- Check if your organization allows custom apps
- Contact your IT administrator
- Try refreshing Teams or restarting the app
- Verify you have the right permissions

### Microphone Not Working

**Problem:** Transcription not capturing audio
**Solutions:**
- **Check microphone permissions** in browser/Teams
- **Test your microphone** in Teams settings
- **Try a different browser** if using web Teams
- **Restart Teams** and try again

### Transcription Not Starting

**Problem:** App loads but transcription doesn't begin
**Solutions:**
- **Verify you're the meeting host** (only hosts can start)
- **Check API keys** if using cloud services
- **Try local transcription mode** as backup
- **Ensure stable internet connection**

### Poor Transcription Quality

**Problem:** Text is inaccurate or missing words
**Solutions:**
- **Speak clearly** and avoid background noise
- **Use a good microphone** or headset
- **Try cloud services** for better accuracy
- **Check audio levels** in the diagnostic panel

### Chat Integration Issues

**Problem:** Transcripts not appearing in chat
**Solutions:**
- **Verify chat permissions** for the app
- **Check if meeting chat is enabled**
- **Wait a moment** - summaries take time to generate
- **Try manual export** if automatic fails

## 🔒 Privacy and Security

### What Data is Collected

**Local Processing Mode:**
- Audio processed on your device only
- Transcripts stored locally
- No data sent to external services

**Cloud Processing Mode:**
- Audio sent to selected AI service
- Transcripts may be temporarily stored
- Follow your organization's data policies

### Best Practices

**For Sensitive Meetings:**
- Use local processing mode
- Enable privacy mode if available
- Review transcripts before sharing
- Delete transcripts when no longer needed

**For Regular Meetings:**
- Cloud services provide better accuracy
- AI summaries are more detailed
- Automatic chat integration works better

## 📋 Quick Reference

### Keyboard Shortcuts
- **Start/Stop Transcription:** Ctrl+Shift+T (when app is active)
- **Toggle Mute:** Ctrl+Shift+M (Teams standard)
- **Open App Panel:** Click Apps → Meeting Transcription

### Status Indicators
- **🟢 Green:** Transcription active and working
- **🟡 Yellow:** Transcription paused or processing
- **🔴 Red:** Error or transcription stopped
- **⚪ Gray:** Not available (not host or no meeting)

### Common Actions
- **Start Transcription:** Host only, click Start button
- **View Real-time Text:** Available to all participants
- **Access Transcripts:** Check meeting chat after meeting
- **Export Transcripts:** Use app's export feature
