## Video Production Guidelines

### Technical Specifications

**Video Quality Standards**:
```
Resolution: 1920x1080 (1080p minimum)
Frame Rate: 30 fps
Audio: 48kHz, 16-bit minimum
Bitrate: 5-8 Mbps for streaming
Format: MP4 (H.264 video, AAC audio)
Captions: SRT format, multiple languages
```

**Screen Recording Setup**:
```
Recording Software: OBS Studio or Camtasia
Screen Resolution: 1920x1080 scaled to fit
Cursor Highlighting: Enabled for clarity
Zoom Effects: For detailed UI elements
Audio Quality: Professional microphone required
```

### Content Guidelines

**Video Structure**:
1. **Introduction** (10-15 seconds): Clear title and overview
2. **Main Content** (80% of video): Step-by-step demonstration
3. **Summary** (10-15 seconds): Key takeaways and next steps
4. **Call to Action**: Links to documentation or next videos

**Presentation Best Practices**:
- **Clear Narration**: Professional, conversational tone
- **Logical Flow**: Step-by-step progression
- **Visual Clarity**: Highlight important UI elements
- **Pacing**: Allow time for viewers to follow along
- **Accessibility**: Captions and audio descriptions

### Accessibility Features

**Visual Accessibility**:
- High contrast cursor and highlights
- Large, readable text in demonstrations
- Clear visual indicators for actions
- Alternative text for visual elements

**Audio Accessibility**:
- Clear, well-paced narration
- Audio descriptions of visual actions
- Background music at appropriate levels
- Multiple language options

**Interactive Accessibility**:
- Keyboard navigation support
- Screen reader compatibility
- Alternative input methods
- Adjustable playback speed
