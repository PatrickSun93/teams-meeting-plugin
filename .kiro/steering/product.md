# Product Overview

## Teams Meeting Transcription Plugin

A Microsoft Teams plugin that provides real-time speech-to-text transcription, speaker identification, and AI-powered meeting summaries.

### Core Features
- 🎤 Real-time meeting transcription with multiple STT providers
- 👥 Speaker identification and diarization
- 🤖 AI-powered meeting summaries with customizable prompts
- 💬 Automatic transcript sharing to Teams chat
- 🔒 Privacy-focused with local and cloud STT options
- ⚙️ Comprehensive configuration management
- 🛡️ Security and consent management system

### Key Value Propositions
- **Privacy First**: Supports local processing with Whisper for sensitive meetings
- **Enterprise Ready**: Comprehensive security, audit logging, and consent management
- **Flexible AI**: Multiple AI providers (OpenAI, Claude, Azure OpenAI) for summaries
- **Teams Native**: Deep integration with Microsoft Teams ecosystem
- **Customizable**: User-defined summary prompts and configuration options

### Target Users
- Enterprise teams requiring meeting documentation
- Organizations with strict privacy requirements
- Teams needing automated meeting summaries and action items
- Users wanting speaker identification in multi-participant meetings
